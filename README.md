# Multi-Language Tic-Tac-Toe (Jogo da Velha) 🎮

Este repositório reúne implementações clássicas do jogo **Tic-Tac-Toe** (Jogo da Velha) escritas em múltiplas linguagens de programação. É um projeto de estudo ideal para comparar a sintaxe, estrutura e orientação a objetos em diferentes ecossistemas.

---

## 📁 Estrutura do Projeto

O projeto é organizado por linguagem:

### 1. [Python (`/python`)](./python)
* **`main.py`**: Versão clássica e procedural estruturada.
* **`TTT_OOP.py`**: Versão moderna implementada utilizando os conceitos de **Programação Orientada a Objetos (POO)**.

### 2. [C (`/c`)](./c)
* **`TTT.c`**: Implementação clássica com manipulação direta de memória, arrays e I/O limpo via terminal.

### 3. [Java (`/java`)](./java)
* **`TTT.java`**: Versão robusta em Java utilizando classes e encapsulamento de estados do tabuleiro.

### 4. [Lua (`/lua`)](./lua)
* **`TTT.lua`**: Implementação elegante utilizando tabelas dinâmicas de Lua e programação funcional simples.

---

## 🚀 Como Executar

### Python
```bash
python3 python/main.py
# ou para a versão Orientada a Objetos
python3 python/TTT_OOP.py
```

### C
```bash
gcc c/TTT.c -o ttt
./ttt
```

### Java
```bash
javac java/TTT.java
java -cp java TTT
```

### Lua
```bash
lua lua/TTT.lua
```
